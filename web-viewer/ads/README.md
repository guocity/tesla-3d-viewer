# Showroom ads

`lgnat.jpg` is the first monitor advertisement: LGNAT.COM in black on white.

Use a wide JPEG (approximately 5.17:1, matching the showroom LED wall).
The original monitor colors alternate with the ad on a 16-second cycle, with smooth transitions. The original LED grid, screen geometry, reflections and light spill are preserved.

To change the displayed ad, replace this JPEG or change the image URL in
`src/ad-screen.js`. Vite bundles the image for development and production.
